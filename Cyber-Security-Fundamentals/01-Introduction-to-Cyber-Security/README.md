# Module 01: Introduction to Cyber Security

## 💡 Module Summary
This module introduces the overarching domains of cyber security, detailing the operational differences between offensive (Red Team) and defensive (Blue Team) security, while mapping out career tracks across the industry.

---

## 🛠️ Key Concepts & Technical Principles

### 1. Offensive Security (Red Teaming)
- Focused on identifying system vulnerabilities, simulating real-world cyberattacks, and assessing structural resilience through authorized exploitation.

### 2. Defensive Security (Blue Teaming)
- Focused on active threat detection, infrastructure hardening, incident response, digital forensics, and maintaining access controls.

### 3. Industry Roles & Career Pathways
- **Penetration Tester / Bug Hunter:** Evaluates applications, networks, and cloud targets for security vulnerabilities.
- **SOC Analyst (Tier 1-3):** Monitors security telemetry, analyzes logs, and isolates active security threats.
- **Security Engineer:** Designs, deploys, and maintains secure technical architecture and defenses.

---

## 📌 Summary Takeaway
Offense and defense rely on the exact same underlying technology mechanisms. Understanding how a system works is the non-negotiable prerequisite to both exploiting and securing it.
